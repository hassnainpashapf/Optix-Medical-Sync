    Questions

    Straight answers

    Short, factual, and about what the software does today.

    Is my hospital's data separate from others?

    Yes. Every workspace has its own database file and its own uploads folder. A user can only ever reach the workspace they signed in to.

    How does the free trial work?

    Create a workspace and use every feature for the trial period. When it ends the workspace becomes read-only until a plan is chosen. Nothing is deleted.

    Where is my data stored?

    In SQLite database files on the server that runs the platform, plus a folder per workspace for uploaded files. Nothing is sent to an outside service.

    What do I need to run it?

    Node.js 24 or newer. There are no packages to install. Start it with one command and open it in a browser.

    Who can see what?

    There are five roles: Super Admin, Doctor, Receptionist, Accountant and Pharmacist. The server enforces them, so a restricted role never receives data it may not read.

    Can I see who changed something?

    Yes. The audit log records every create, update and delete, plus sign-ins, with the user and the time. Only a Super Admin can open it.

    What if something goes wrong?

    The database is copied to a backups folder on every start and once a day. The last seven copies are kept, and a Super Admin can also back up on demand.

    Does it send SMS or email reminders?

    Not yet. That needs a messaging provider account, so it is planned rather than included.

    Does it work on a phone?

    The app is designed for desktop and tablet screens. This website is fully responsive.
